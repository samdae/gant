# 5거래일 돌파 가설

GANT v3는 새 가격 스냅숏에 `price-breakout-v1` 가설을 저장한다. 예측 모델이 몇 %의 상승 확률을 제시하든 같은 규칙을 적용한다. 가설·검증 기간·재검토 기준을 자료와 함께 미리 기록하는 방식은 [Trade Hypothesis Ideator](https://github.com/tradermonty/claude-trading-skills/tree/main/skills/trade-hypothesis-ideator)를 참고했다. 해당 도구의 가설 생성 프롬프트나 순위 평가기는 실행하지 않는다.

| 조건 | 발행 시 고정하는 값 | 만기 때 검증하는 값 |
|---|---|---|
| 돌파 가설 | 기준일을 포함한 최근 5개 완료 거래일의 **장중 고가** 중 최댓값 | 이후 다섯 번째 거래일의 **종가**가 기준을 초과하면 성립 |
| 재검토 조건 | 같은 과거 5거래일의 **장중 저가** 중 최솟값 | 이후 5개 거래일의 **종가** 중 최솟값이 기준을 밑돌면 성립 |

기준과 같은 가격에서는 조건이 성립하지 않는다. 두 조건은 독립적이다. 예를 들어 둘째 날 하단을 이탈한 뒤 다섯째 날 상단을 넘으면 두 조건이 모두 성립한다. 종가 최솟값이 여러 날 같으면 가장 이른 거래일을 표시한다. 기준일 종가는 별도로 기록한다.

## 가격과 시각

한국 종목은 KRW와 한국 거래소, 미국 종목은 USD와 뉴욕 거래소 거래일을 사용한다. 발행에 사용하는 종목 기호·거래소·시간대·통화는 공급자 메타데이터로 확인한다. 한국의 일봉 출처는 NAVER, 미국은 Yahoo Finance다. 캘린더 기준 마감 후 20분부터 관측할 수 있고 다음 거래일 개장 전에만 예측을 발행한다. 같은 시장·종목이라도 휴장과 조기 종료를 반영하므로 5거래일은 반드시 5달력일과 같지는 않다.

발행 경로는 최근 21거래일 시세가 완전하고 분할 또는 불확실한 기업행위 표시가 없는지 확인한다. 저장 단계에서도 과거 5일의 OHLC로 경계를 다시 계산한다. 만기에는 동일 종목·거래소·통화·출처의 예정된 5개 일봉을 모두 대조한다. 결측이나 중복 일봉이 있으면 이후 거래일로 밀거나 가격을 보간하지 않는다. 늦은 자료는 7일의 수집 유예 기간에 재확인한다. 분할이나 조정 기준이 불확실한 배당 등의 경우는 검증 대상에서 제외한다. 이 검사는 공급자에게서 받은 표시를 사용한다.

결과 확정 전에는 조건이 `pending`, 결과 제외 시에는 `unavailable`이다. 실제 종가가 검증되면 `met` 또는 `not_met`와 관측값·날짜를 결과와 같은 DB 트랜잭션에 기록한다. 기존 전향 사례의 기준을 사후에 만들어 넣지 않는다.

## 확률과 이슈

기존 상승 사건의 정답은 다섯 번째 종가가 다음 거래일 시가보다 높은지로 정한다. 돌파·재검토 상태가 Brier 점수나 기억 비교 표본을 바꾸지 않는다. 새 가설과 기사는 기본·단일·토론·기억 예측의 시장 입력에서 제외된다. 목록의 `forecast_probabilities`에는 실제 발행한 방법만 포함한다.

새 사례의 이슈 목록은 사례 생성 트랜잭션 안에서 `lab_case_issue_evidence`에 고정한다. 발행일과 최초 관측 시각을 확인할 수 있는 최근 30일 자료만 담는다. 이후 재수집이나 동일 사례 등록 재시도는 기존 이슈 목록을 교체하지 않는다. 공개 DTO는 날짜와 링크 형식을 다시 검증한다. 링크는 보도 출처를 열람하기 위한 것이며 기사 내용의 독립 검증이나 가격 변동의 인과관계를 표시하지 않는다. [이슈 수집 규칙](ISSUES.md)

## 재현 검증

프로젝트 루트에서 실행한다. 저장소 검증은 명시한 PostgreSQL 바이너리로 임시 클러스터를 생성한다.

~~~powershell
$env:PG_TEST_BINDIR = Join-Path $env:LOCALAPPDATA 'TradingAgentsDeploy/pgsql/bin'
.\.venv\Scripts\python.exe -m unittest discover -s tests -p test_forecast_lab_hypothesis.py
.\.venv\Scripts\python.exe -m unittest discover -s tests -p test_forecast_lab_engine.py
.\.venv\Scripts\python.exe -m unittest discover -s tests -p test_forecast_lab_store.py
~~~

가설 테스트는 경계값과 같은 종가, 최초 최저 종가 날짜, 통화 불일치, 중복 일봉, 기존 시장 입력 해시 보존을 확인한다. 저장소 테스트는 변조된 기준 거부, 이슈 최초 동결, 잘못된 관측 통화 거부, 결과의 원자적 저장과 재시도를 확인한다.

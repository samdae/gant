목표는 주가 방향 판단을 발행 시점 자료로 재현하고, 만기가 지난 뒤 어떤 근거와 기억이 도움이 되었는지 확인하는 것이다. v2의 종목별·포트폴리오 모드와 읽기 전용 콘솔을 계승한다. v3는 Windows 독립 체크아웃과 새 PostgreSQL 클러스터를 사용한다. 운영 주소의 전환은 별도 릴리스로 관리한다.

## 기획과 구현의 순서

구현 전에 기획과 검증 계약을 기록한다. 담당자가 나뉘어 구현하고, 실제로 달라진 계약·검증 결과·재시작 방법은 같은 변경에서 갱신한다. 개발 세션의 기억은 사용자 환경에 보관하고 시장 판단에 쓰이는 학습 표본은 v3 서비스에서 전향적으로 수집한다.

## 검증 계약

1. 발행 시 가격 스냅숏에서 측정 가능한 가설과 재검토 조건을 동결한다. 어떤 기준 시세·날짜·통화를 썼는지 표시한다. 조건의 성립 여부는 발행 후 실제 관측값으로만 평가하며 자료가 없으면 평가 대기로 구별한다. 조건 평가가 다섯 거래일 상승 확률·Brier 점수·동일 사례 기억 비교의 정답을 바꾸지 않는다.
2. 최근 30일 이슈를 수집하는 제품 작업은 전용 수집 명령에서 실행한다. 출처·제목·공개 시각·최초 관측 시각을 저장하며 두 시각이 모두 예측 시점 이전인 근거만 조회한다. 수집 장애, 출처 없음, 시장 인과관계 미확인은 그대로 드러낸다. 초기 릴리스에서는 이슈를 별도 근거로 열람하고 확률 입력 변경은 독립적인 실험으로 검증한다.
3. 예측 연구 화면에서는 회사명과 발행 확률, 관측 기간, 검증 결과를 먼저 읽는다. 선택한 사례에서 당시 가격, 조건, 시점이 맞는 시장 이슈와 출처, 방법별 확률을 조사할 수 있어야 한다. 모바일 및 공개 조회에서 동작하고, 빈 표본에는 실제 상태를 표시한다.
4. Impeccable과 claude-mem은 개발자 도구로 운영한다. last30days의 개발자용 검색과 서비스 수집의 설치·데이터·실행 지점을 분리한다. 외부 레포를 통째로 제품에 포함하지 않는다. 주가 예측력 개선은 만기가 지난 공통 사례에 대한 전향 비교로만 평가한다.

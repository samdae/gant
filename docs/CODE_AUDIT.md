## 메인 에이전트의 재현 결과

- Git 추적 대상 .env.dev에 현재 운영 관리자 자격과 동일한 값이 있다. 로컬 설정 보존 및 추적 해제, 향후 개발 템플릿과 운영 자격 분리가 필요하다.
- PostgreSQL URL 생성기가 암호의 @, /, # 등을 인코딩하지 않는다. 초기화·리셋 스크립트도 같은 코드를 복제한다. reset-db.ps1은 운영 DSN 우선순위 때문에 개발 포트 재정의를 우회할 수 있다.
- Yahoo 기술 지표의 과거 날짜 요청이 오늘 기준 창을 내려받는다. Alpha Vantage는 네트워크 타임아웃이 없으며 HTTP 예외의 URL에 키가 포함될 수 있다.
- Windows 시작기는 프록시를 열기 전 동일 포트의 다른 프로세스를 구분하지 않는다. 백업은 같은 초의 동시 실행에서 디렉터리가 충돌한다.

## 검증 기록

- Windows의 별도 임시 PostgreSQL 17 클러스터와 테스트 픽스처를 사용했다. 통합 unittest 17개 통과. 강제 실패 후 원장 롤백·재시도, 전량 매도, 다중 통화·부분 체결, 권한·큐 정리, 과거 시계열·네트워크 예외를 포함한다.
- Svelte 검사 오류 0 / 경고 0, Node 캐시 회귀 테스트 통과, 공개용 프런트 빌드 통과. Python compileall과 Ruff 미정의 참조 등 선별 규칙 검사 통과.
- 운영 데이터 이력에 보정 거래를 삽입하지 않았다. 실시간 시점의 대시보드 기준 USD +2.06%, KRW +0.99%, 활성 포지션 0. 불완전 원장 USD 18건·KRW 22건. 이 값은 확인된 체결에 한정되며 순입금 대비 계좌 수익률과 다르다.
- 운영 릴리스는 web-20261123-audit. 운영 관리자 토큰을 교체한 뒤 빈 요청으로 구 자격 401 / 새 자격 정상 인증 후 입력 검증 422를 확인했다. 운영 비밀은 보고서·로그에 기재하지 않는다.
- 실계정 OAuth 재로그인, 신규 유료 모델 실행, 전체 장 운영 및 PC 재부팅은 이번 회귀 테스트 범위 밖이다. 불완전 과거 체결의 실제 가격·수량은 원천 증빙이 있어야 복원할 수 있다.
운영 브라우저 검증에서 Cloudflare가 이전 sw.js를 최대 4시간 캐싱한 점을 확인했다. Nginx에 서비스 워커와 HTML의 no-store를 적용했다. 기존 CDN 캐시가 만료되기 전에는 기존 화면이 보일 수 있다.

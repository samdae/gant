# 🚨 TradingAgents Issues (Reported by Master DH)
**Date:** 2026-02-19
**Status:** Analysis Pending

## 1. 스케줄 복구 실패 (Resilience)
- **증상:** 스케줄 작업 중(`running` 상태) 시스템 강제 종료 시, 재기동 후 해당 스케줄이 복구되지 않고 누락됨.
- **예상 원인:** `schedule_jobs` 테이블의 상태가 `running`으로 남은 채 좀비가 되거나, 재기동 시 `pending`이나 `failed`로 리셋하는 로직 부재.

## 2. 매수 전략 필드 부재 (Missing Strategy)
- **증상:** 매수 결정이 나왔으나 구체적인 전략(Strategy) 정보가 없음.
- **확인 필요:** `reports` 테이블의 `investment_plan` 외에 구조화된 전략 필드가 필요한지 검토.

## 3. 자본금 및 잔고 관리 (Budget Calculation)
- **증상:** 초기 자본금($5000) 설정 후 첫 거래는 되나, 이후 거래 시 잔고 차감 및 가용 자금 계산이 제대로 되는지 불확실.
- **확인 필요:** `PortfolioAgent` 또는 트레이더 로직에서 `remaining_budget` 관리 여부. DB에 `account_balance` 같은 상태 저장소가 안 보임.

## 4. 데이터 불일치 (Data Inconsistency)
- **증상:** 
  - "최근 활동": 구글, 엔비디아, 앰디바이스 매수/진입 표시됨.
  - "트레이드 메뉴": 적용 안 됨.
  - "AI 분석 메뉴": 엔비디아만 매수 상태로 뜸.
- **예상 원인:** `schedule_job_events`(로그), `reports`(분석 결과), `trades`(실제 체결), `positions`(보유) 테이블 간의 데이터 동기화 또는 트랜잭션 누락. UI가 바라보는 소스가 다름.

## 5. 목록 중복 및 누락 (UI/Query Bug)
- **증상:** "최근 활동"에서 구글 2개 중복 노출, 하이닉스 누락.
- **예상 원인:** SQL 쿼리(`SELECT`) 시 `DISTINCT` 누락 또는 정렬/Limit 문제. 프론트엔드 렌더링 키 중복 등.

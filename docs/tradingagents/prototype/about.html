12개 AI가 주식을 분석하고, 가상 매매로 검증하며, 실패에서 스스로 배우는 시스템.

AI 에이전트가 경험을 축적하여 스스로 판단을 개선할 수 있는가를 검증하는 실험 플랫폼입니다.

두 가지 모드

이 시스템은 분석검증 모드와 포트폴리오 모드 두 가지로 동작합니다. 12에이전트 파이프라인은 동일하고, PA(판단·실행) 이후만 다릅니다.

분석검증 모드

지향: 분석 정확도 순수 측정

종목별 독립 자금(USD $5,000 / KRW ₩5,000,000). PA는 실행자 — 파이프라인 결론을 그대로 실행. 변수를 최소화해 "분석이 맞았는지"만 검증합니다.

포트폴리오 모드

지향: 배분(밸런싱) 품질

공유 가상 자금 풀. 비서 에이전트가 전체 티커 분석을 압축하고, PortfolioManagerAgent가 리밸런싱을 결정. 주간 정기 반성으로 배분 품질을 평가합니다.

핵심 원리

대부분의 AI 분석 도구는 분석하고 끝입니다. 결과를 내놓고, 맞았는지 틀렸는지는 확인하지 않습니다.

이 시스템은 분석 → 가상 매매 → 결과 확인 → 매매검증(반성) → 경험(RAG) 저장 → 다음 판단에 반영하는 루프를 돌립니다.

실패에서 배운다가 핵심입니다. 청산된 포지션마다 매매검증(반성)으로 교훈을 추출하고, 그 경험(RAG)을 저장한 뒤, 다음 분석 시 PA가 40% 비중으로 참고합니다.

실제 매매는 수행하지 않습니다. 모든 매매는 가상이며, 분석의 정확도를 검증하기 위한 수단입니다.

분석 파이프라인

4명의 분석가가 시장·소셜·뉴스·재무를 독립 분석한 뒤, Bull↔Bear 토론, Research Manager 판결, Trader 제안, 3자 리스크 토론, Risk Judge 최종 결정을 거쳐 Portfolio Agent가 매매 수량을 결정합니다.

학습 사이클

가상 매매로 결과를 추적하고, 청산 시 매매검증(반성)과 회고분석이 각각 다른 역할을 합니다.

매매검증(반성)

교훈 생성 → RAG 저장. "이 포지션에서 무엇을 배웠나?" 반성문과 핵심 레슨을 추출해 경험(RAG)으로 저장합니다. 다음 PA 판단 시 40% 비중으로 참조됩니다.

회고분석

과정의 타당성 수치화. 분석 정확도(0~100): 12에이전트 분석이 시장 움직임과 얼마나 일치했는가. RAG 기여도(0~100): 경험(RAG)이 PA 판단에 얼마나 기여했는가. 사용자 요청 시 별도 실행되며, 대시보드에 평균 배점이 표시됩니다.

분석 → 매매 → 청산 시 매매검증 → RAG 저장 → 다음 판단 반영 ↺

회고분석 배점은 자동 루프가 아닙니다. 수동 요청 시 실행됩니다.

RAG Validator란?
회고분석 결과를 바탕으로 RAG 문서별 유용성을 평가합니다. PA가 해당 경험(RAG)을 실제로 반영했는지 문서 단위로 판정하고, usefulness_score를 ±1 조정합니다. 40 미만이면 검색에서 배제되어 쓰레기 경험이 점진적으로 걸러집니다.
포트폴리오 RAG 교차 참조
분석검증 PA는 포트폴리오 반성을 참조하지 않습니다 (변수 통제). 포트폴리오 PA는 분석검증 반성 + 포트폴리오 반성 모두 참조합니다. ChromaDB 컬렉션도 모드별로 분리되어 있습니다.
